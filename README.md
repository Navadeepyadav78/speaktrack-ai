# speaktrack-ai
AI-powered communication practice and growth tracker for students

##Problem 
students often practise presentations and interviews without objective feedback about their speaking habits.

##solution 
SpeakTracker AI analyses short speaking sessions and provides 
measurable feedback on speech and camera-related metrics.

##Planned Features 
- Speech-to-text
- Speaking pace analysis
- Fillr-world detection
- pause analysis
- face visibility analysis
- practice history
- progress tracking

  ##AI technologies
  - whisper
  - face/pose analysis
  - ONNX Runtime
  - Qualcomm AI hub models

## Target Platform 
Snapdragon-powered HP PCs

##Status
Prototype development
